# ぬい憑き

Progateハッカソン powered by ProjectLINKS（2026年11月）で開発するプロダクトです。

## サービスの概要

「ぬい憑き」は放置された推しのぬいぐるみを連れて街を歩くぬい活アプリです。国土交通省Project LINKSの空き家データなどから、地点ごとの「怨念度」を計算します。怨念度の高い場所でぬいを撮影すると、ぬいに怨念が宿り、ARで動き出します。動くぬいはそのまま短い動画として保存できます。宿った怨念はぬいを構うほど鎮まっていきます。

## 作った背景

推しへの熱は、時間がたつと薄れがちです。しかし、放置されたぬいぐるみには怨念が宿ります。そこで、ぬいを空き家など人に忘れられた場所へ連れて行くと、怨念が目覚めて動き出す仕組みを作りました。怒るぬいを構い直すうちに、推しへの熱をもう一度取り戻してほしいと思い、このアプリを作りました。

## 推し技術

PythonとpandasでProject LINKSなどのオープンデータを整え、地点ごとの怨念度を機械学習で推定します。怨念度は位置情報と組み合わせて乗り移りの確率に変え、Webの画面ではARでぬいを動かします。データの読み込みと怨念度の計算は分けて作ります。中間発表で配られる新しいデータも、すぐに判定の材料として足せます。

## 技術スタック

- Web（フロントエンド、AR）
- Python（機械学習）
- pandas（データの読み込みと整形）
