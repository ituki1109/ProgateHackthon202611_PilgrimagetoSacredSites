# AR 試作（マーカー追跡）

ぬいに付けた名札（画像マーカー）をスマートフォンのカメラで追跡し、ぬいの上に「憑依」の演出を重ねる試作です。マーカーが映っている間、演出がマーカーと一緒に動けば MVP とします。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面。three と MindAR は import map で CDN から読み込む |
| `main.js` | マーカー画像から照合データを作り、MindAR でカメラ映像を追跡する |
| `effects.js` | オーラ、人魂、吹き出しの演出（Three.js） |
| `marker.js` | 標準マーカーの模様を描く |
| `marker.html` | 標準マーカーを表示・印刷・PNG 保存するページ |

照合データ（`.mind`）は起動のたびにブラウザーの中でマーカー画像から作ります。ファイルを用意しなくても、自分の画像をマーカーに選べます。

## 動かし方

リポジトリの直下で静的サーバーを起動し、`http://localhost:8000/ar/` を開きます。

```bash
python -m http.server 8000
```

スマートフォンのブラウザーでカメラを使うには HTTPS が必要です。スマートフォンで試すときは、GitHub Pages に置くか、トンネル（cloudflared など）で HTTPS の URL を作ってください。

## 試し方

1. パソコンで `marker.html` を開き、マーカーを画面に表示するか、5cm 角で印刷します。
2. スマートフォンで `index.html` を開き、「はじめる」を押します。
3. マーカーを映すと、オーラと人魂と吹き出しが出ます。

## 分かっていること

- ブラウザーの中で照合データを作るので、初回は数秒から20秒ほどかかります。標準マーカーの照合データを `.mind` ファイルとして置けば、この待ち時間をなくせます。
- 自分の画像を使う場合は、模様が細かく、色の差がはっきりした画像ほど追跡が安定します。
