# AR 試作（マーカー追跡）

ぬいに付けた名札（画像マーカー）をスマートフォンのカメラで追跡し、ぬいの上に「憑依」の演出を重ねる試作です。マーカーが映っている間、演出がマーカーと一緒に動けば MVP とします。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面。three と MindAR は import map で CDN から読み込む |
| `main.js` | マーカー画像から照合データを作り、MindAR でカメラ映像を追跡する |
| `effects.js` | オーラ、人魂、吹き出しの演出（Three.js） |
| `puppet.js` | カメラ映像からぬいを切り取り、変形させて動いて見せる |
| `config.js` | ぬいと名札の寸法、腕や首の位置 |
| `marker.js` | 標準マーカーの模様を描く |
| `marker.html` | 標準マーカーを表示・印刷・PNG 保存するページ |

照合データ（`.mind`）は起動のたびにブラウザーの中でマーカー画像から作ります。ファイルを用意しなくても、自分の画像をマーカーに選べます。

## 動かし方

リポジトリの直下で静的サーバーを起動し、`http://localhost:8000/ar/` を開きます。

```bash
python -m http.server 8000
```

スマートフォンのブラウザーでカメラを使うには HTTPS が必要です。スマートフォンで試すときは、GitHub Pages に置くか、トンネル（cloudflared など）で HTTPS の URL を作ってください。

## 試し方

1. パソコンで `marker.html` を開き、マーカーを画面に表示するか、3cm 角で印刷します。
2. スマートフォンで `index.html` を開き、「はじめる」を押します。
3. マーカーを映すと、ぬいが揺れたり手を振ったりして、オーラと人魂と吹き出しが出ます。

## ぬいを動かす仕組み

本物のぬいは動かせないので、画面の上で動いて見せています。

1. ぬいの位置に、細かく分割した板を置きます。
2. 板の各点が変形する前に画面のどこに映るかを計算し、そこのカメラ映像を板に貼ります。何も変形させなければ、板は本物のぬいとぴったり重なります。
3. 板を変形させると、貼った映像も一緒に動きます。体全体の揺れと跳ね、首から上の傾き、左右の腕の振りを付けています。
4. 動いたあとに本物のぬいが見えないよう、その下にぬいのすぐ外側の映像を引き伸ばした板を敷き、ぬいを隠します。

## 分かっていること

- ブラウザーの中で照合データを作るので、初回は数秒から20秒ほどかかります。標準マーカーの照合データを `.mind` ファイルとして置けば、この待ち時間をなくせます。
- 演出の大きさは全長11cmのぬいに3cm角の名札をお腹に付けた想定で決めています。名札やぬいの大きさを変えたら、`config.js` の `MARKER_CM`、`NUI_CM`、`TAG_HEIGHT_RATIO` を直してください。
- 3cm角の名札は小さいので、カメラから20〜40cmくらいまで近づけないと認識しにくいことがあります。
- 自分の画像を使う場合は、模様が細かく、色の差がはっきりした画像ほど追跡が安定します。
- ぬいの輪郭は楕円で近似しているので、ぬいのまわりの床も少し一緒に動きます。ぬいを隠す塗りつぶしは無地の床や壁の前だとなじみますが、模様の多い場所では筋が見えます。
- 腕と首の位置は、写真のぬいに合わせて `config.js` の `PARTS` で決めています。ぬいによって合わないときはここを直してください。
