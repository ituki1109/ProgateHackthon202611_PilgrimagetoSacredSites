# 使うデータ

推薦地点を作るために使うオープンデータです。対象地域は **富山県高岡市** です。

## 高岡市を選んだ理由

Project LINKS のデータを推薦に使える地域だからです。

Project LINKS の公開データのうち、市の中の地点の評価に使えるのは「空き家・空き地バンク登録物件データ」だけでした。このデータは物件ごとに最寄り駅を持っているので、駅の位置と結びつけると、駅ごとの登録物件の数が分かります。高岡市は登録物件が158件あり、そのうち136件が28駅に分かれていて、駅ごとの違いを出せます。

川崎市も検討しましたが、空き家バンクに川崎市の物件はありませんでした。観光統計は都道府県単位、鉄道とバスは事業者単位のデータなので、どの地域でも地点の評価には使えません。

デモは録画か、現在地を自由に変えられる画面で行うので、会場（川崎）から離れた地域でも問題ありません。

## データの一覧

| データ | 提供元 | 使い道 | ライセンス |
|---|---|---|---|
| 高岡市施設一覧 | 高岡市 | 推薦地点（名前、種類、緯度経度） | CC BY 2.1 JP |
| 駅別乗降客数 | 国土交通省（国土数値情報） | 駅の位置と、1日の乗降客数 | CC BY 4.0 |
| 空き家・空き地バンク登録物件データ（2025年度） | 国土交通省（Project LINKS） | 駅ごとの登録物件の数 | 公共データ利用規約 第1.0版（CC BY 4.0 互換） |

ダウンロードしたファイルは `data/raw/` に置きます（git には入れません）。

### 高岡市施設一覧

- ページ: https://www.city.takaoka.toyama.jp/soshiki/johoseisakuka/2/3/1/1/5117.html
- ファイル: `20260401_sisetu.csv`（2026年4月1日版、Shift_JIS）
- 件数: 834件。緯度経度がないのは12件
- 使う列: `新番号`、`ジャンル`、`施設名称`、`所在地`、`緯度`、`経度`
- `ジャンル` の件数: 公園・緑地 422、子育て 106、コミュニティ施設 73、環境・衛生 40、学校・教育 35、交通 29、スポーツ 28、文化・生涯学習 23、市庁舎 18、健康・福祉 17、公営住宅 15、観光・産業 14、防災 2、空欄 12

推薦地点にするのは、ぬいを連れて行ける次のジャンルだけです。

- 公園・緑地
- 観光・産業
- 文化・生涯学習
- スポーツ

学校、子育て、公営住宅、市庁舎などは外します。中身を見て、ほかにも連れて行きにくい施設（ごみ処理場など）があれば外してください。

### 駅別乗降客数

- ページ: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-S12-2024.html
- ファイル: `S12-25_GML.zip`（2024年度版、6.6MB）。中の `UTF-8/S12-25_NumberOfPassengers.geojson` を使う
- 地物: 駅ごとの線（LineString）。中心の点を駅の位置とする
- 使う列: `S12_001`（駅名）、`S12_002`（運営会社）、`S12_003`（路線名）、`S12_061`（2024年度の1日の乗降客数）。乗降客数は2011年度から年度ごとに4列ずつ並び、その最後の列が `S12_061`
- 高岡市の駅: JR（城端線、氷見線、北陸新幹線）、あいの風とやま鉄道、万葉線の各駅が入っている
- 同じ駅が路線ごとに複数行ある（例: 高岡）。乗降客数は路線ごとの行に分かれ、0 の行もあるので、駅名でまとめて合計する

### 空き家・空き地バンク登録物件データ

- ページ: https://www.geospatial.jp/ckan/dataset/links-akiyabank-2025
- ファイル: `01_tourokubukken.csv`（2025年3月31日時点、UTF-8）
- 件数: 全国で7,746件。高岡市は158件で、最寄り駅が入っているのは136件
- 使う列: `PREFECTURE`、`CITY`、`NEAREST_STATION`
- 高岡市の物件の最寄り駅は28駅で、すべて駅別乗降客数の駅名と一致する

駅ごとの登録数（多い順）: 高岡 38、越中中川 12、伏木 12、高岡やぶなみ 10、福岡 8、片原町 6、新高岡 6、戸出 5、広小路 4、西高岡 4、急患医療センター前 4、米島口 3、江尻 3、二塚 3、ほか14駅が1〜2件。

## spots.json の作り方

1. 施設一覧から、上のジャンルで緯度経度のある施設を取り出す
2. 各施設に、いちばん近い駅（駅別乗降客数の駅）を結びつける
3. 施設ごとに次の値を `attrs` に入れる

| `attrs` の項目 | 内容 |
|---|---|
| `nearest_station` | いちばん近い駅の名前 |
| `station_distance_m` | その駅までの直線距離（メートル） |
| `station_passengers` | その駅の1日の乗降客数（路線の合計） |
| `akiya_count` | その駅を最寄りとする空き家バンク登録物件の数 |

`category` には `ジャンル` の値（「公園・緑地」など）をそのまま入れ、`id` は `takaoka_` に `新番号` を付けた値にします。

## 推薦のルール（案）

点数は次の3つを 0〜1 にそろえて重みを付けて足します。重みはデモを見ながら調整してください。

| 要素 | 重み | 考え方 |
|---|---|---|
| 現在地からの近さ | 0.5 | 近いほど高い。2km より遠い地点は 0 |
| `akiya_count` | 0.3 | 多いほど高い。ふだん人が目を向けにくい街へ出かけるきっかけにする |
| 駅からの近さ | 0.2 | ぬいを連れて電車で行きやすい |

推薦理由は、たとえば次のようになります。

> 伏木駅から徒歩6分の公園・緑地。この駅を最寄りとする空き家バンクの登録物件は12件。

徒歩の分数は、直線距離を 80m で割って切り上げます（直線距離なので目安です）。

## データを使うときの注意

- 空き家バンクの登録物件は、地域にある空き家のすべてではありません。「空き家が多い」「人が少ない」とは書かず、「空き家バンクの登録物件が何件」と事実だけを書きます。
- Project LINKS のデータは紙の報告書から作られており、完全性と正確性は保証されていません。
- 3つのデータとも、使うときは出典の表示が必要です。画面のどこかに、次の出典を出します。

> 出典：高岡市「高岡市施設一覧」、国土交通省「国土数値情報（駅別乗降客数データ）」、国土交通省 Project LINKS「空き家・空き地バンク登録物件データ」を加工して作成
