# AR の憑依

ぬいに付けた名札（画像マーカー）をカメラで追跡し、ぬいの上に「憑依」の演出を重ねるページです。記録の結果画面の「憑依を見る」から開きます。アプリの画面とは別のページなので、three と MindAR は AR を開いたときだけ読み込みます。

中間発表では AR を見せないので、今はこのボタンを隠しています。`frontend/js/visit.js` の `SHOW_AR` を `true` にすると出ます。隠している間も、`/ar/` の URL を開けば動きます。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面。three と MindAR は import map で CDN から読み込む |
| `main.js` | URL の値を読み、MindAR でカメラ映像を追跡する |
| `effects.js` | オーラ、人魂、吹き出しの演出（Three.js）。怨念の段階で見せ方を変える |
| `puppet.js` | カメラ映像からぬいを切り取り、変形させて動いて見せる |
| `config.js` | ぬいと名札の寸法、腕や首の位置 |
| `marker.js` | 標準の名札の模様を描く。照合データも作る |
| `marker.html` | 標準の名札を表示・印刷するページ。照合データを作り直すボタンもある |
| `marker.mind` | 標準の名札の照合データ |

## URL の値

結果画面は `ar/?nui=1&name=もちもち&grudge=70` の形で開きます。`grudge` でセリフと演出が変わり、`nui` は戻る先に使います。`ar/` だけで開くと、怨念 100 の演出になります。

## 動かし方

API のサーバーがこのページも配ります。パソコンのカメラで試すときは、`http://localhost:8000/ar/` を開きます。カメラは HTTPS か localhost でしか使えないので、スマートフォンで試すときは、トンネル（cloudflared など）で HTTPS の URL を作ってください。

## 試し方

1. `marker.html` を開き、名札を4cm 角で印刷して、厚紙に貼り、ぬいのお腹に付けます。別の端末の画面に表示して試すこともできます。
2. `index.html` を開き、「はじめる」を押します。
3. 名札を映すと、ぬいが揺れたり手を振ったりして、オーラと人魂と吹き出しが出ます。

`marker.js` の模様を変えたら、`marker.html` の「照合データ（marker.mind）を作る」で作り直し、`marker.mind` を置き換えてください。

## ぬいを動かす仕組み

本物のぬいは動かせないので、画面の上で動いて見せています。

1. ぬいの位置に、細かく分割した板を置きます。
2. 板の各点が変形する前に画面のどこに映るかを計算し、そこのカメラ映像を板に貼ります。何も変形させなければ、板は本物のぬいとぴったり重なります。
3. 板を変形させると、貼った映像も一緒に動きます。体全体の揺れと跳ね、首から上の傾き、左右の腕の振りを付けています。
4. 動いたあとに本物のぬいが見えないよう、その下にぬいのすぐ外側の映像を引き伸ばした板を敷き、ぬいを隠します。

## 分かっていること

- 自分の画像を名札にすると、ブラウザーの中で照合データを作るので、数秒から20秒ほどかかります。標準の名札は `marker.mind` を読むので、この待ち時間はありません。
- 演出の大きさは全長14cmのぬいに4cm角の名札を付けた想定で決めています。名札やぬいの大きさを変えたら、`config.js` の `MARKER_CM`、`NUI_CM`、`TAG_HEIGHT_RATIO` を直してください。URL で `?markerCm=3&nuiCm=14&tagRatio=0.36&tilt=10` のように渡すと、直さずに試せます。
- 名札の上側がぬいの体より手前に傾いて見えるときは、`tilt` で角度を足すと演出がぬいの向きに合います。
- MindAR の認識には、次の決まりがあります。名札が映像の中で 100px ほどより小さいと認識できません。名札を探すのは映像の中央付近だけです（1080p で横の中央 53%、720p で 40%）。追跡は1回の処理で名札の幅の8%ほどしか動きを追えないので、処理の回数が少ないと速い動きを見失います。
- `?debug=1` を付けると、実際のカメラの解像度と処理の回数を画面に出します。
- ぬいの顔を目印にする方法も試しましたが、実機では印刷した名札のほうが精度がよかったので、名札を使っています。

## 名札を目立たせない方法

- 画面の中で名札を消します。名札のまわりの毛の色で塗る処理で、認識には影響しません。見失っている間は名札が見えます。`?hideTag=0` で止められます。
- 自分の画像を使う場合は、模様が細かく、色の差がはっきりした画像ほど追跡が安定します。
- ぬいの輪郭は楕円で近似しているので、ぬいのまわりの床も少し一緒に動きます。ぬいを隠す塗りつぶしは無地の床や壁の前だとなじみますが、模様の多い場所では筋が見えます。
- 腕と首の位置は、写真のぬいに合わせて `config.js` の `PARTS` で決めています。ぬいによって合わないときはここを直してください。
